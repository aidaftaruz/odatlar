# Odatlar daftari

Kundalik odatlar va kaloriya daftari. Veb ilova, telefon va kompyuterda ishlaydi.

## GitHub Pages'ga qo'yish

1. GitHub'da yangi **Public** repo oching, masalan `odatlar`.
2. **uploading an existing file** ni bosing va shu papkadagi hamma fayl va papkani sudrab tashlang.
3. **Commit changes** ni bosing.
4. **Settings → Pages** ga kiring. **Source: Deploy from a branch**, **Branch: main**, papka **/ (root)** ni tanlang va **Save** ni bosing.
5. 1–2 daqiqadan keyin ilova `https://<nomingiz>.github.io/odatlar/` manzilida ochiladi.

Telefonda Chrome'da oching, keyin uchta nuqta → **Bosh ekranga qo'shish**.
Ma'lumotlar o'sha brauzerda saqlanadi. Bir marta ochilgandan keyin internetsiz ham ishlaydi.
